# コンテナ for YMM4
 
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)

YukkuriMovieMaker4（YMM4）上で動作する、**複数の映像エフェクトをタブで管理するプラグイン**です。
タブごとに独立したエフェクト構成を保持し、タブの切り替えによって複数のエフェクト構成を素早く使い分けることができます。
タブのドラッグ＆ドロップ並べ替え、コピー・ペースト・複製、待避（スタッシュ）によるタブの一時退避と復元、名前付きブックマークによるエフェクト構成の永続保存と再利用、スタッシュ・ブックマークから個別エフェクトを現在のタブへ抽出する機能、画面幅に応じた自動コンパクトモード、8 言語対応の UI を搭載しています。

## 概要
 
本プラグインは YMM4 の「映像エフェクト」として動作する、タブ式エフェクト管理ツールです。
タイムライン上のアイテムに追加された「コンテナ」ひとつの中に複数のタブを持ち、タブごとに独立した映像エフェクト構成を格納できます。各タブのエフェクトはパイプラインとして上から順に処理されます。
 
プロパティパネルのラベルには現在のタブ名と格納エフェクト数が `コンテナ [タブ名] (N個)` の形式で表示されるため、タイムライン上での内容の把握が容易です。
 
待避（スタッシュ）はタブのエフェクト構成を一時的に退避・復元する機能で、スタッシュ・ブックマークはいずれも YMM4 プロジェクト横断でグローバルに保持されます。

## インストール方法
 
1. [Releases](https://github.com/routersys/YMM4-Container/releases) ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4 が起動していないことを確認し、ダウンロードしたファイルを実行（ダブルクリック）してインストールします。
3. YMM4 を起動し、タイムライン上のアイテムを選択します。
4. 映像エフェクトの追加から **「コンテナ」** を選択してください。

## 主な機能
 
### 1. エフェクトのグループ化
 
YMM4 の標準の映像エフェクトセレクター（`VideoEffectSelector`）を内包しており、任意の映像エフェクトを複数格納して順番に適用できます。格納されたエフェクトは上から順にパイプライン処理され、無効化されたエフェクト（`IsEnabled = false`）はスキップされます。
 
- **ラベル表示**: タイムラインおよびプロパティパネルのラベルに現在のタブ名とエフェクト数が `コンテナ [タブ名] (N個)` 形式で表示されます。
- **カテゴリ**: 映像エフェクトの「装飾」カテゴリに分類されます。タグは「コンテナ」です。
- **AviUtl 非対応**: 本エフェクトは AviUtl 出力（`ExoVideoFilters`）には対応していません。
### 2. エフェクトタブ管理
 
プロパティパネル上部にタブバーが表示され、タブごとに独立したエフェクト構成を保持できます。タブを切り替えると選択中タブのエフェクト構成が「適用中エフェクト」に即座に反映されます。
 
- **タブを追加**: タブバー右端の「＋」ボタンでタブを追加します。タブ名は自動で「タブ N」（N はタブ数）が付与されます。
- **タブを削除**: 各タブの「×」ボタンで削除します。タブが 1 枚のみの場合は削除できません。最後の 1 枚を残そうとすると「×」ボタンは無効化されます。タブを削除してすべてのタブがなくなった場合、「新規」タブが自動的に生成されます。
- **タブ名を変更**: タブ名をダブルクリックして編集できます（Enter またはフォーカス移動で確定、Esc でキャンセル）。
- **タブを切り替え**: タブをクリックすると、そのタブのエフェクト構成が「適用中エフェクト」に反映されます。
- **ドラッグ＆ドロップ並べ替え**: タブをドラッグして任意の位置へ移動できます。ドロップ位置にはダイヤモンド形のマーカーが付いたインジケーターが表示されます。
- **既定のタブ名**: 初回作成時の先頭タブは「新規」、それ以降に追加したタブは「タブ N」が自動で付きます。
- **マウスホイールスクロール**: タブバー上でマウスホイールを操作すると、親要素にスクロールイベントが伝達されます（タブバー自体はホイールでは横スクロールしません）。
### 3. コピー・ペースト・複製
 
タブ内のエフェクト構成をクリップボードまたは複製操作で別タブへ転用できます。クリップボード形式は独自形式（`Container.EffectTab`）のため、テキストとしては貼り付けられません。
 
- **コピー**: タブのコンテキストメニューから「コピー」を選択すると、タブ名とエフェクト構成をクリップボードにコピーします。
- **ペースト（タブ指定あり）**: タブのコンテキストメニューから「貼り付け」を選択すると、そのタブのエフェクト構成をクリップボードの内容で上書きします。タブ名は変更されません。
- **ペースト（タブ指定なし）**: タブバーの空白領域のコンテキストメニューから「貼り付け」を選択すると、クリップボードの内容から新しいタブを末尾に追加します。タブ名にはコピー元のタブ名 + 「 (コピー)」が付与されます。
- **複製**: タブのコンテキストメニューから「複製」を選択すると、そのタブの直後に同じエフェクト構成のタブをタブ名 + 「 (コピー)」として追加します。
### 4. 待避（スタッシュ）
 
タブのエフェクト構成を一時退避（スタッシュ）し、後から新しいタブとして復元できます。スタッシュはプロジェクト横断でグローバルに保持されます。
 
- **待避**: タブのコンテキストメニューから「待避」を選択します。タブ名とエフェクト構成がスタッシュとして保存され、元のタブは削除されます。スタッシュ名は以下の形式で自動生成されます。
  - エフェクトが複数の場合: `On {タブ名}: {先頭エフェクト名} (+他{残り件数}件)`
  - エフェクトが 1 件の場合: `On {タブ名}: {エフェクト名}`
  - エフェクトが 0 件（空タブ）の場合: 待避は実行されません。
- **スタッシュの確認**: タブバーの空白領域のコンテキストメニュー「待避」サブメニューにスタッシュ一覧が表示されます。スタッシュが 0 件の場合はサブメニュー自体が非表示になります。各スタッシュにはエフェクト構成のツールチップが表示されます。
- **復元**: 「待避」サブメニューからスタッシュを選択すると、「スタッシュから復元」という名前の新しいタブとして末尾に追加します。復元後、そのスタッシュは一覧から削除されます。
- **スタッシュの個別削除**: 「待避」サブメニューの各スタッシュ項目にある「×」ボタンで個別に削除できます。
- **スタッシュの全削除**: 「待避」サブメニューの「すべて削除」リンクをクリックすると、確認ダイアログの後にすべてのスタッシュを削除します。
### 5. ブックマーク
 
エフェクト構成に名前を付けて永続保存する機能です。待避（スタッシュ）とは異なり、ブックマーク時に元のタブは削除されません。ブックマークはプロジェクト横断でグローバルに保持されます。
 
- **ブックマーク追加**: タブのコンテキストメニューから「ブックマーク」を選択します。ダイアログで名前を入力して「作成」すると保存されます。エフェクトが空のタブはブックマークできません（警告メッセージが表示されます）。
- **ブックマークの確認**: タブバーの空白領域のコンテキストメニュー「ブックマーク一覧」サブメニューにブックマーク一覧が表示されます。ブックマークが 0 件の場合はサブメニュー自体が非表示になります。各ブックマークにはエフェクト構成のツールチップが表示されます。
- **復元**: 「ブックマーク一覧」サブメニューからブックマークを選択すると、ブックマーク名と同じ名前の新しいタブとして末尾に追加します。ブックマーク自体は削除されません。
- **編集**: 「ブックマーク一覧」サブメニューの各ブックマーク項目にある鉛筆ボタンから編集ダイアログを開きます。「完了」で名前を変更、「削除」でブックマークを削除できます。
- **ブックマークの全削除**: 「ブックマーク一覧」サブメニューの「すべてのブックマークを削除」リンクをクリックすると、確認ダイアログの後にすべてのブックマークを削除します。
### 6. エフェクト抽出
 
スタッシュまたはブックマーク内の個別エフェクトを、現在選択中のタブへ追加できます。
 
- **操作**: タブのコンテキストメニュー「エフェクトを抽出」サブメニューに「待避」と「ブックマーク一覧」が表示されます（それぞれが 1 件以上ある場合のみ表示）。
- **サブメニュー構造**: 各スタッシュ・ブックマークをさらに展開すると、その中に格納されているエフェクトが一覧表示されます。目的のエフェクトを選択すると、現在選択中タブのエフェクトリスト末尾に追加されます。
### 7. コンパクトモード
 
タブバーの幅が足りなくなると、自動的にコンパクト表示に切り替わります。
 
- **発動条件**: タブ数 × 120px がタブバーの実際の幅以上になった場合にコンパクトモードが有効になります。
- **コンパクト表示**: 各タブが 28px 幅に縮小されます。タブラベルにはタブ名の先頭 1 文字（名前が空の場合はインデックス番号）が表示されます。閉じるボタン（×）は非表示になります。
- **ホバー時の展開**: コンパクトモード中にタブへマウスカーソルを合わせると、そのタブが 120px 幅に一時展開してフルネームと閉じるボタン（×）が表示されます。
- **編集モード中の例外**: タブの名前編集中（`IsEditing = true`）のタブはコンパクトモードが適用されず、常にフル幅で表示されます。
### 8. 多言語対応
 
ローカライズファイルを内蔵しており、YMM4 の言語設定に合わせて UI テキスト、ダイアログメッセージ、ボタンラベルがすべて自動で切り替わります。
 
対応言語：日本語 (`ja-jp`)、英語 (`en-us`)、中国語簡体字 (`zh-cn`)、中国語繁体字 (`zh-tw`)、韓国語 (`ko-kr`)、スペイン語 (`es-es`)、アラビア語 (`ar-sa`)、インドネシア語 (`id-id`)

## パラメータ一覧
 
プロパティエディタで設定可能な項目は以下の通りです。
 
| パラメータ名 | 型 | デフォルト | アニメーション | 説明 |
|---|---|---|---|---|
| **適用中エフェクト** | ImmutableList | (空) | ✗ | 現在選択中のタブに格納された映像エフェクトのリスト。YMM4 標準のエフェクトセレクターで追加・並べ替え・無効化ができます。タブ切り替え時に自動更新されます。 |
| **EffectTabsJson** | String (JSON) | (空文字列) | ✗ | タブ状態（選択中タブ ID・タブ名・各タブのエフェクト JSON）を保持する内部用プロパティです。タブの追加・削除・名前変更・切り替え・並べ替え時に自動更新されます。 |
| **SelectedTabName** | String | (null) | ✗ | 現在選択中のタブ名を保持する内部用プロパティです。タイムラインラベルの `[タブ名]` 部分の表示に使用されます。タブ切り替え・名前変更時に自動更新されます。 |
 
> タブ管理コントロール（`EffectTabManagerControl`）はプロパティパネル上部に、エフェクトセレクターはその下に表示されます。どちらも「コンテナ管理」グループとして表示されます。

## 使い方ガイド
 
### コンテナを追加する
 
1. タイムラインで映像アイテム（動画・画像など）を選択します。
2. 映像エフェクトの追加から「コンテナ」を選択します。
3. プロパティパネルにタブバーとエフェクトリストが表示されます。
4. エフェクトリストに任意の映像エフェクトを追加してください。
### 複数のエフェクト構成をタブで使い分ける
 
1. タブバー右端の「＋」ボタンでタブを追加します。
2. 各タブで異なるエフェクト構成を作成します。
3. タブ名をダブルクリックして用途に合わせた名前に変更します。
4. タブをクリックして切り替えると、選択中タブの構成が即座に「適用中エフェクト」に反映されます。
### タブのエフェクト構成を別のタブに転用する
 
1. コピー元のタブを右クリックして「コピー」を選択します。
2. コピー先のタブを右クリックして「貼り付け」を選択すると、そのタブのエフェクト構成がクリップボードの内容で上書きされます。
3. タブバーの空白領域で右クリックして「貼り付け」を選択すると、クリップボードの内容で新しいタブが追加されます。
### タブを一時退避（スタッシュ）して後から復元する
 
1. 退避したいタブを右クリックして「待避」を選択します。タブが削除され、エフェクト構成がスタッシュとして保存されます。
2. 復元したいときは、タブバーの空白領域を右クリックして「待避」サブメニューから該当のスタッシュを選択します。「スタッシュから復元」タブとして末尾に追加されます。
### エフェクト構成をブックマークとして永続保存する
 
1. 保存したいタブを右クリックして「ブックマーク」を選択します。
2. ダイアログで任意の名前を入力して「作成」をクリックします。元のタブはそのまま残ります。
3. 後から利用したいときは、タブバーの空白領域を右クリックして「ブックマーク一覧」サブメニューから該当のブックマークを選択します。ブックマーク名のタブが末尾に追加されます（ブックマーク自体は削除されません）。
### スタッシュ・ブックマークから特定のエフェクトだけ追加する
 
1. エフェクトを追加したいタブをアクティブにします。
2. そのタブを右クリックして「エフェクトを抽出」サブメニューを開きます。
3. 「待避」または「ブックマーク一覧」から目的のスタッシュ・ブックマークを展開します。
4. 追加したいエフェクト名を選択すると、現在選択中タブのエフェクトリスト末尾に追加されます。
### ブックマークを編集・削除する
 
1. タブバーの空白領域を右クリックして「ブックマーク一覧」サブメニューを開きます。
2. 対象のブックマーク項目にある鉛筆ボタンをクリックします。
3. 編集ダイアログで「完了」を選択すると名前を変更、「削除」を選択するとブックマークを削除します。

## 注意事項
 
- AviUtl 形式（`.exo`）への出力には対応していません。
- スタッシュとブックマークは YMM4 の設定ファイルとしてグローバルに保存されます。プロジェクトをまたいで共有されますが、設定ファイルを削除するとすべてのスタッシュ・ブックマークが失われます。
- 待避（スタッシュ）操作は、エフェクトが 1 件以上あるタブにのみ有効です。エフェクトが空のタブは待避できず、スタッシュに追加されません。
- ブックマーク操作も同様に、エフェクトが空のタブはブックマークできません。警告メッセージが表示されます。
- タブが 1 枚のみの状態では「×」ボタンは無効化され、削除できません。
- タブを削除してタブが 0 枚になった場合は、「新規」タブが自動的に生成されます。
- ペースト操作はクリップボードにコンテナ独自形式（`Container.EffectTab`）のデータが含まれている場合のみ有効です。テキストや画像など他のクリップボードデータには対応していません。
- スタッシュの全削除・ブックマークの全削除はいずれも確認ダイアログが表示されます。
- 「コンテナ」内に同じ「コンテナ」を入れ子にすることは推奨しません。
